# Learned Programs

This folder contains reusable executable programs created or materially developed by Robot-Codex during operation.

Do not move every temporary script here. Promote a program when it appears reusable beyond the current episode and future sessions would benefit from discovering and invoking it.

Each promoted learned program should have:

- a corresponding semantic playbook in `Playbooks/Learned/`;
- an entry in `Playbooks/Index.md`;
- provenance and evidence in the relevant session report;
- clearly stated limitations and applicable robot/configuration scope.

Temporary one-off code may remain an ordinary session artifact without becoming part of the learned program library.
