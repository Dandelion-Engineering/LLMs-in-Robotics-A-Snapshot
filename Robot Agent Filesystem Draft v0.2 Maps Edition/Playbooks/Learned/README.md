# Learned Playbooks

This folder contains reusable procedures that Robot-Codex develops during operation and promotes beyond a single episode.

A script or procedure should not become a learned playbook merely because it was created. Promote it when the agent has reason to believe it is reusable and future sessions would benefit from discovering it.

A learned playbook should:

- describe what the capability does and when to use it;
- point to any reusable program in `Programs/Learned/`;
- state scope, preconditions, safety constraints, and limitations;
- point to session evidence supporting the promotion;
- be registered in `../Index.md`.

Use `../PlaybookTemplate.md` as the semantic wrapper.
