# From recovery measurements to a limited empirical cell

This is a construction procedure and non-authorizing helper, not a qualification decision. It was prepared from current source and planned interfaces without opening pending physical outputs, running physics, using evaluation seeds, changing Runtime, or choosing numerical limits. The root task selected **parking1** as the primary destination because the unchanged common recovery policy tries it first. Retain both declared destination construction sets; parking2 measurements cannot silently authorize parking1.

## Minimum sequence and artifacts

1. Run the declared construction phase through the shared queue. Keep every attempted, failed, unstarted and deferred row in the unchanged full plan. Completion of the process and its succeeded/exit-0 receipt establish execution, not physical qualification.
2. Run `Recovery Qualification/extract_screen.py --screen COMPLETED_DIR --queue-receipt SAVED_RECEIPT --output FRESH_DIR` through the shared queue. Its `extraction.json` is the completion marker. It retains indexed source/receipt identities, one `trial.json` per declared trial, exact rich `measured-states.json` with event/line/payload/file references, sampled/dense geometry summaries and original raw evidence references. Boundary trials outside the half-open generator domain stay explicitly outside it.
3. Run this folder's `bundle_construction.py --construction-extraction .../extraction.json --destination parking1 --output FRESH_DIR`. It produces `construction-dossier.json` and `provisional-rule.draft.json`. It hashes the extracted bytes it consumes, preserves all statuses and exact coupled state tuples, and indexes family/payload-location groups. It does **not** verify all raw evidence afresh, fit a min/max box, choose a successful subset, choose a measured cell, or fill a numerical limit. The draft has no cells or absence bound and deliberately cannot pass the provisional validator.
4. Use construction observations to write the smallest supported provisional cells, explicit coupled-state transfer assumption, corridor representation, absence convention and untested scope. Pin the class specification and construction extraction by file-byte hashes; pin the class's canonical digest separately. Hash/copy the completed rule **before** running the originally reserved independent validation phase. Fixed independent world draws are not validation of a rule fitted after seeing their outcomes.
5. Evaluate those untouched validation observations against exactly that rule. Retain failures, out-of-cell states and all exposure counts. A failed or unsupported validation does not license changing the rule while calling the same observations untouched validation. Revise the affected scope transparently only if needed, then obtain a new untouched development check for that revised claim; there is no automatic broad screen or fixed additional trial quota.
6. Only after reviewing that support may the protected operator construct `prior-restart-class-qualification-1`, set `status: measured_development`, record its acceptance time, and later bind it in the release freeze. `load_restart_qualification` independently verifies its artifact bytes and exact frozen mapping; `qualified_entry_identity` still performs class/source checks; `_grip` and `_route` still evaluate the actual cut. No helper in this folder makes the physical acceptance/readiness decision.

## Preserve coupled observations and locations

Keep each cut as one tuple: payload template and ID, actual source position, relative payload pose/rotation, jaw width, both finger forces, payload velocities/bottom height, all joint/finger positions and velocities, native control target, actual other bodies, source identities and cut phase. Pair it with the same trial's immediate post-cancel state, end-of-hold state, pre-dispatch state, actual route and settled outcome. Route classification currently compares its start ranges with the **cut** snapshot, while physical recovery starts after the hold. The rule must explicitly cover that measured cut→hold→dispatch relationship; do not substitute the dispatch state for the cut without changing the declared semantics.

Current `_grip` and `_route` use separate axis-aligned/scalar ranges. Their numerical predicate admits a Cartesian product of those ranges; retaining correlated rows alone does not make that product measured. A deliberately local cell can be accepted as a **finite empirical transfer assumption** with construction support and untouched validation, while stating that interior combinations remain unmeasured. Do not label marginal minima/maxima as a measured Cartesian domain or hide the assumption in a free-form success statement. Do not add an epsilon to a degenerate observed coordinate to make a strict box validator pass; any nonzero width must have an explicit representation/transfer rationale and validation scope.

Maintain separate A and B support. The current planned public rule selects A1 for A and lexically first visible B; the ten-part construction pickup is B10, while smaller populations can select a different B raw location. Preserve actual ID and coordinates rather than pooling by equal box dimensions. `family_pickup_groups` is an index, never an automatic equivalence argument. The current frozen mapping supports one cell per template (`part:A` / `part:B`), with the same declared parking destination. If one limited B cell supports only one observed pickup region, other B starts remain unknown/fail under its actual state predicates. Broadening to several B locations requires explicit support for that broader coupled cell or a separately reviewed deterministic location/cell interface; no post-outcome search for the favorable cell is allowed.

Construction failures remain in the dossier even when a narrower prospective cell excludes their states. Explain exclusions by observable state/source conditions before validation, rather than by a `passed` flag. Inserts, fixture pickups, processed-part/tray pickups, low-clearance carries, other cut phases, other pads and unobserved absence durations remain unsupported unless their own evidence establishes scope.

## Whole-arm and payload geometry at discrete physics ticks

The fixture owner's agreed low-cost addition is a dense in-memory accumulator. At every normal physics tick, compute a conservative world AABB for each inventoried robot collision geometry and every payload geometry from the native cached transform and exact compiled local outer box. For a local center `c`, half-size `h`, world transform `(R,p)`, the outer bounds are `p + R c ± abs(R) h`. Rotated compiled mesh local boxes conservatively enclose the actual mesh; they may overestimate occupancy. Keep every geometry and its role/method/inventory/source identity.

Accumulate minima/maxima per geometry until the existing coarse trace write; flush the interval union, first/last simulation clocks, tick count and largest tick gap. Keep phase unions as a secondary summary. Forced cut/cancel/hold/dispatch boundaries must belong to clearly labeled intervals; avoid losing the final partial interval. Preserve the native cached-transform/qpos alignment convention. The accumulator describes the native evaluated geometry states, not silently recomputed transforms for a differently timed qpos. No full per-tick JSON stream or extra physics step is necessary.

For each coarse interval, compare the dense union with the union of its coarse endpoint/sample boxes. Per geometry and axis, the observed omitted excursion is:

`max(0, coarse_min - dense_min, dense_max - coarse_max)`.

The maximum over those retained coordinates is an **observed discrete sampling deficit**. It is not a derivative bound, continuous sweep guarantee, or allowance for unseen trajectories. Endpoint displacement, peak sampled joint speed, or a nominal 50 Hz rate alone supplies none of those guarantees. Joint-angle extrema plus kinematic reach propagation can be conservative under explicit assumptions, but the direct dense geometry accumulator is simpler and tighter for these recorded discrete traces.

Use the per-interval, per-geometry dense outer boxes as the proposed corridor basis. One giant phase-wide or workspace-wide box can create unnecessary blockers; retain smaller intervals without dropping any geometry/state. Any extra representation/transfer padding must be a separately stated empirical choice from construction variation and tested by the untouched validation. Keep `observed_coarse_sampling_deficit_m`, the actual corridor construction method and any `transfer_allowance_m` distinct in supporting artifacts. The current scalar `route_sampling_clearance_allowance_m` is required provenance metadata; `_route` does **not** expand boxes by that number. The actual `clearance_corridors_m` must already include every declared expansion.

Discrete scope is sufficient for the intended explicitly empirical transfer claim. The bundle must state it; it must not claim formal continuous collision avoidance. Whole-geometry coverage, complete tick/gap accounting and dense-union containment in the frozen corridor must be checked on validation too. If a gap, unsupported geometry, transform convention mismatch or out-of-corridor state occurs, retain it as unsupported; do not invent a missing interval bound. If the first construction trace lacks the dense accumulator, the smallest missing measurement is a focused replay of the same affected physical route/location with the accumulator, not interpolation of sparse saved states masquerading as observed dynamics.

`_route` tests the supplied corridors against actual **other movable bodies** at the cut and exact destination-region equality. Fixed geometry is pinned by class/source identity and must be represented in the construction collision/contact analysis. Retain robot–fixed-world, self, payload and other-body contacts/distances throughout the route, distinguishing intentional grip/placement/base contacts under an explicit common rule. Do not claim `_route` itself performs a new static-world path search or proves future obstacles remain still. The existing state/device predicates and measured fixed controller behavior remain part of the conditional scope.

## Absence and outcome support

The absence coordinate must use one explicit clock and endpoint. For `recover_held_admitted`, capture the conservative before-cancel start, preserve the same hold checks through both the declared initial hold and fresh sensing/reconciliation, and stop only at actual accepted recovery admission. Preserve both simulation and wall clocks; the five-second subinterval alone cannot cover a longer total hold. The fixture owner is adding those endpoint and per-tick observations. The supervisor loader separately records the actual operational interval; a missing/exceeded interval remains unsupported despite a successful final placement.

Required retained facts are actual bilateral carry, uninterrupted recorded-tick hold within the declared endpoint interval, complete route geometry/contact support, independent settled placement with open empty jaws and no pending work, and untouched development validation of the provisional rule. Sampling cannot prove between-state grip persistence; label the discrete evidence accurately. Final success or a transport receipt alone does not supply a grip/route/absence envelope.

## Provisional rule and final bundle interface

`bundle_construction.PROVISIONAL_SCHEMA` is `provisional-restart-class-rule-1`. A completed prospective rule uses status `provisional_development_rule`, timezone-qualified `created_at`, destination, `{path,sha256}` construction-extraction and class-spec references (plus class `canonical_sha256`), selection rule `unique_bilateral_payload_template`, a deterministic template-to-cell map, complete tentative cell envelopes/support descriptions, explicit absence settings, geometry scope `discrete_native_evaluated_states_empirical_transfer`, empirical-transfer text, untested combinations and `validation_outcomes_used_for_fitting:false`. The validator checks identity/completeness only; it returns `qualification_granted:false` and does not judge physical or numerical support.

After untouched validation, the final bundle must preserve the exact provisional rule hash and validation launch binding, full trial indexes including failures/deferred rows, independently verified source/evidence refs and the unchanged tentative cell values. Add actual validation support, acceptance time and artifact references without retrospectively widening the cells. The final class bundle uses the existing `QUALIFICATION_SCHEMA`, `class_spec`, cells and required support categories; the protected freeze uses the loader's existing file/canonical hashes, fixed mapping and absence convention. Run the protected loader and actual classifier on retained construction/validation snapshots as a consistency check, keeping source-domain exclusions and missing support explicit. Passing that structural check is still not readiness.
