# Exact root-choice provisional rule assembler

`assemble_provisional_rules.py` is a queue-only construction tool. It reads the exact root-authored choice bytes (`0dc4687822db5229e6d9fead06c39516facd06c6452f047d90e2e25b5ba406a5`), fresh optimized-source construction extraction, both destination dossiers and compact reports, and their official successful receipts. Runtime `restart_state.py` must match the completed construction and current source SHA-256 `d5f354c60af83c6f9d32f6b43a893c19486ddcb1f8d2f85c78f526fe48d0273c`. Other archived Runtime source identities are also compared to current bytes. No numerical fitting, validation outcomes, physics, qualification grant, or Runtime/source edits occur.

For parking1 and parking2 separately, it materializes exactly the root's two A1/B10 cells, root numbers and derived center ± half-width ranges. Relative rotation is copied from the exact same-destination corner-A-5/corner-B-5 cut; destination geometry is copied from that protected cut. The fixed 50 mm compact cover is expanded by exactly 10 mm per axis. Every original group route and actual cut-scene comparison, exact input containment and zero strict/native-policy-AABB blockers at that padding must be present. The class specification is copied as exact original protected bytes with both file and canonical identities. Thin measured cut points retain three identity hashes plus event/trial/measured-state refs; full coupled witnesses stay external.

`route_sampling_clearance_allowance_m=0.0` means no further allowance beyond the materialized coordinates. It is not an observed coarse sampling deficit or a continuous bound. The separate 10 mm transfer assumption, dense coverage/statistics, compact cover and original trace refs remain explicit. Per-interval observed coarse deficits remain in those source traces and are not rescanned/summarized by this assembler.

`CompletedExtraction` provides the existing source, raw/derived artifact and landmark binding. Dossiers are matched exactly against regeneration from that same extraction and their official command/output/time. Compact receipts and embedded queue/source/input identities are checked. No extra whole-geometry scan is introduced. The existing hold assessment is evaluated on rebound landmarks/child records with the same accepted-admission wall-clock convention: admission wall timestamp minus HoldWindow start wall timestamp. Every available hold/clock/admission/host-timing/settled-child-flag check must pass, and the full accepted-admission duration must support five wall seconds. Its separate independent dwell-event check remains explicitly unassessed in this construction preflight; no synthetic event or pass is manufactured. The unchanged final validation assessor still requires it.

All in-domain A1/B10 cuts must satisfy the fixed numerical predicate and protected class. Every original in-domain B2 cut must fail an actual mapped part:B TCP or joint-start predicate; object IDs are not admission gates. Out-of-domain boundary cuts remain explicit class exclusions, with original physical/timing outcomes retained. Only in-domain A1/B10 cut witnesses populate measured-point lists. Any selected-construction contradiction or unknown evidence prevents **both** rule files from being written; `construction-membership.json` records the failure and every declared trial/status. Initial input/receipt errors may abort before that report exists and must retain their official failed attempt.

On success, output contains immutable `parking1/provisional-rule.json`, `parking2/provisional-rule.json`, each destination's exact `class-spec.json`, and `construction-membership.json`. Rules remain provisional and contain empty `evidence_refs`; they are not accepted bundles. They include required loader metadata, root choices, source refs, class exclusions, numerical B2 exclusions and the complete original trial-status index. Their creation time precedes any later untouched validation. No excluded or failed trial is rewritten as passed.
