## Shared description to show once

“Each episode runs one candidate policy process, with at most one outstanding model request. The local model gateway runs outside that candidate process; executor and sensing workers are infrastructure, not additional LLM agents. A1, A2 and A3 use the same selected local text model and inference limits. The current setup selects Qwen3-14B Q4_K_M with thinking disabled; the proposed 4B design and earlier 4B attempts remain historical. The final release manifest supplies the exact model identity. Calls receive structured public observations derived from the image adapter and device I/O, not raw RGB input to a vision-language model. Shared planning, actuator control and the protected evaluator remain outside the language model. Physics continues during planning and inference.”
