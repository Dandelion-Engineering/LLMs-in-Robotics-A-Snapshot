# Independently verified qualified restart continuity

[qualified_restart.py](qualified_restart.py) adds an operator adapter used by [continuity.py](continuity.py). It leaves legacy v1 exact-configuration evidence explicitly labeled as recorded predicate/hash interpretation. A restart carrying qualified-class evidence, or an episode declaring a qualification identity, cannot fall back to that legacy interpretation when independent context is missing.

This adapter is implemented and synthetically tested. It has not read a real qualification bundle or scored episode. Root has now integrated `Runtime/restart_calibration_loader.py`, its release/protocol loader and experiment event wiring. Production use still requires freezing that implementation with actual measured qualification artifacts. Integration alone does not establish physical qualification or readiness. The [loader and event contract](../Batch%2001/Restart%20Qualification%20Tools/WIRING.md) is the upstream interface.

The standalone extractor accepts explicit `--release-dir <protected-evaluation-release>` in addition to `--episode-dir` and fresh `--output`. The [evaluation processor](process_evaluation.py) supplies the release automatically. Development/legacy extraction remains available without it; qualified exposure without independently supplied context stays unknown. The adapter never follows an event's claimed freeze path as authority.

The authority chain is the supplied protected release whose hash must match the episode authorization, its exact planned run manifest/hash, and the release's freeze reference also bound by that manifest. For qualified mode, the adapter verifies the frozen code index and every executable helper it imports: `restart_compatibility.py`, `restart_physical_class.py`, `restart_qualification.py`, `restart_state.py`, and `restart_calibration_loader.py`. The loader independently rehashes the exact bundle and all referenced calibration artifacts. Their identities, plus release/run/freeze/reader identities, remain in the operator report and are rechecked before/after extraction and writing. This chain establishes source identity; it does not replace canonical terminal selection or statistical eligibility.

At each qualified-mode restart, the adapter compares the recorded identity to the independently loaded identity, recomputes frozen deterministic selection (including no selected cell for an empty cut), compares the exact embedded calibration, and reruns the frozen classifier. The original at-cut report remains visible. Any inconsistent source/hash, deterministic selection, calibration or classifier is refused rather than silently corrected. For carry scope, the actual duration/coverage record is independently checked as well.

The reader requires protected capture, classification and before/after cancellation landmarks for both carry and supported empty cuts. Capture simulation time must equal the before-cancel simulation time under the current single physics-owner sequence; wall capture/classification cost remains recorded separately. No new numerical age tolerance is introduced. For `closed_grip_transfer`, actual absence is a later required fact: the reader recomputes duration from before-cancel to the exact endpoint using the independently frozen timebase and bound. It verifies restart/incarnation and event-parent correlation, exact readiness facts, or the first novel accepted nonpassive control and its frozen recovery destination. Duplicate-suppressed and passive actions do not end the hold; an unsupported first control cannot be replaced by a later favorable one.

If the qualified endpoint is first admitted recovery, `restart_ready` supplies only an elapsed lower bound. No qualifying endpoint, ambiguous/missing clocks, simulation advancement before revocation, or an exceeded measured absence bound leaves qualified admissibility unknown. An episode-end observation retains its elapsed lower bound; it is never assigned zero. Final task success cannot repair missing coverage. An independently failed physical at-cut predicate remains inadmissible even when absence coverage passes.

Carry-qualified admissibility requires both independently recomputed at-cut admissibility and covered actual absence. Supported empty cuts (`after_acceptance`, `after_release`, `before_outcome`) instead retain independently verified **instantaneous** admissibility, with carry absence coverage explicitly `not_applicable`. This makes no claim about duration support or future recovery. Neither scope establishes recognition, restored validity or useful resumption; the existing conservative recovery requirements remain. Operator annotations stay attributed but cannot waive missing independent context or applicable carry-absence support. Original task validity and paired-block eligibility are never altered by this adapter. [Empty cut reader correction](Empty%20cut%20reader%20correction.md) records the exact scope and counters.

Coverage separates `known_admissible_qualified_context` from `known_admissible_recorded_or_annotated`. Independently verified context includes both empty and carry scopes; dedicated counters separate them, and absence pass/unknown applies only to carry cuts. Missing legacy counters remain unknown. The evaluation processor includes those small counters in its descriptive summaries. Full predicate, calibration and event material remains in linked per-run continuity files.
