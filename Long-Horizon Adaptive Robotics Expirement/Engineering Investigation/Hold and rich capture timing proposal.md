## Safe class-export optimization direction

The implemented target is repeated **class descriptor recomputation**, while retaining every rich capture and every fresh authority/device/observation record. The [native-surface manifest](Native%20surface%20optimization/manifest.json) preserves the historical staged implementation, [patch](Native%20surface%20optimization/native-surface.patch), and archived exact original source; the separate integration record establishes application. [Twelve focused checks](native_surface_checks.py) passed before integration. The root-queued [benchmark](benchmark_native_surface.py) officially succeeded under job `20260923T084415083917Z-00143ee6`, ending 08:44:18.121406 UTC. [The benchmark report](Native%20surface%20optimization/Benchmark%20001.md) records the results and limits.

A private exporter-owned memo can retain a previously verified canonical model descriptor together with an exact baseline of every exposed native field. At every export it must still enumerate the complete live exposed property structure. For each array it must compare current dtype, shape and all bytes with the verified baseline; for scalars it must compare exact type/representation, including signed zero; nested options/visual/statistic objects and any new property must also be checked. Allowed process-mark colors must be checked on every call and normalized only by the existing binary-color rule. Recheck the current seal, XML, registry and requested physical-configuration identity as before.

Only an exact fresh match reuses a prior descriptor hash. Any new, missing or changed field is materialized and hashed using the original representation and finite/unsupported-property policy; the full resulting descriptor must still match the freshly checked seal. Malformed or unsupported input retains the original fail-closed unknown result. The baseline is retained only after this full comparison passes. A caller-supplied flag, snapshot, class report or model ID cannot establish it. The model key is weak, with a tested explicit identity match; byte-tree values do not retain the model. Retiring a model releases its baseline. Seal identity and mark indices also enter the memo key. Returned class payloads are copied fresh from the current seal and never expose the memo.

This trades one retained native-byte baseline per live observed model for C-level exact comparisons, saving repeated array hashing and finite scans, and skipping descriptor serialization when the entire live tree matches. Mark-color validity and normalized-color hashing still run every call. The complete live property enumeration also runs every call. On the one-model static benchmark, warm class-export median wall time changed from 25.02025 to 9.7624 ms and warm rich-capture median from 27.98365 to 12.7093 ms. First memo-cold rich capture changed from 26.2229 to 25.8089 ms. These measurements isolate operation cost; they do not establish host real-time performance during physics.

Dropping the repeated live model scan solely because the single physics owner has not stepped would leave model mutation undetected and is not acceptable. No Runtime capture call sites, dynamic authority fields, cut/absence times, predicate thresholds or physics behavior are changed by this patch.
