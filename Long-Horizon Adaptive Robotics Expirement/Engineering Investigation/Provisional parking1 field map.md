# Parking1 provisional-cell field map

[parking1-provisional-cells.example.json](parking1-provisional-cells.example.json) is one intentionally incomplete example, not a rule to launch or a qualification bundle. All numerical bounds, times, hashes and evidence assertions are null. Array lengths and fixed schema literals reflect the existing validators. The A1/B10 cell IDs are labels only. Copy supported values from a **future final construction's new source/class bindings**, then author the coupled empirical-transfer judgment before independent validation. Do not reuse dossier001 hashes or fit values from later validation outcomes.

| Template field | Exact input or required authoring decision |
| --- | --- |
| `construction_extraction` | Final completed `extraction.json` file path/SHA, retained screen receipt and successful extraction receipt. Final dossier `construction_extraction` repeats the file ref. |
| `class_spec` | The final extraction trial's `protected_class_spec` / `artifact_refs["protected-class-spec.json"]`; retained raw `protected-class-spec.json` file path/SHA and its canonical JSON digest. Must be present in a bound final construction trial. Copy the whole descriptor unchanged; its `required_source_hashes`, components, templates and domain bind the actual new implementation/assets/build. |
| `payload_template_sha256` | Canonical digest of the final descriptor's `templates["part:A"]` or `templates["part:B"]`. This is not the hash of A1/B10's full instance. |
| `measured_points` | Final dossier `trials[].coupled_points[]`, with the matching actual A1 or B10 payload and retained trial/event refs. Copy the three required hashes together: snapshot, physical configuration, class observation. Preserve the entire coupled witness; do not combine hashes or marginal values from different points. The point's source is the final extracted `measured-states.json` landmark. |
| Grip width, forces, relative pose/rotation | The same point's `robot.jaw_width_m`, `contact.left_normal_force_N/right_normal_force_N`, and `payload_pose.relative_to_tcp.position_m/rotation`. Author a proper reference rotation and supported angular deviation; element-wise rotation minima/maxima are not a rotation envelope. |
| Grip speed and bottom limits | Point `payload.linear_velocity`, `payload.angular_velocity` and `payload.bounds.min[2]`. Runtime tests vector norms for speeds. Finite observed extrema alone do not prove the intervening combinations. |
| Route TCP, joints and velocities | Point `robot.tcp_position_world_m`, seven `joint_position_rad` / `joint_velocity_rad_s` entries and two `finger_velocity_m_s` entries. Keep grip and route in the same measured cell; do not independently select favorable marginal ranges. |
| `destination_region_m` | Copy exact `states.<bound landmark>.payload.geometry.zones.parking1` from final extracted `measured-states.json`. Dossier points do not carry the complete zones dictionary. Runtime requires exact region equality, not a fitted or enlarged zone. |
| `clearance_corridors_m` | Future compact output for the matching location: a reviewed `<location>-bin-10mm/20mm/50mm.json` cover, with chosen uniform padding explicitly materialized into each bound. Keep its full-containment report, fixed-padding comparisons, original interval audit and successful receipt. Neither the helper nor this template selects a bin/padding. B10 never borrows B2/A1 geometry. |
| `route_sampling_clearance_allowance_m`, `route_coverage_method` | Explicit engineering account of selected cover/padding, final interval cadence/gaps and containment, and any measured sampling allowance. Compact hull expansion is added space; it does not by itself supply a measured continuous-motion allowance. Preserve discrete cached-transform and untested-interior limits. |
| `measured_state_cell_basis`, `source_scope`, both `untested_combinations`, `empirical_transfer_rule` | Root-authored coupled-transfer claim and its limits, grounded in the final dossier's all-trial outcomes, source bindings and compact comparisons. No Cartesian product of marginal extrema is automatically supported. Preserve physical/timing failures, boundary-domain differences, B2 and all other unmeasured locations/interiors as unsupported. |
| Top-level `absence` | Prospective bound, clock (`simulation` or `wall`) and endpoint. Final `trial.json.child_result.details.cut_to_recovery_admission`, measured-state cut/accepted `recovery_admission` clocks, and final dossier admission record provide duration evidence. The existing assessment supports `recover_held_admitted`; the fixture does not establish a `restart_ready` bound merely by recording another landmark. Five seconds before fresh sensing is not automatically the full admission window. |
| `created_at`, `status` | Timezone-bearing time after the final construction extraction and before prospective validation starts. Only a complete reviewed rule changes status to `provisional_development_rule`; completeness grants no physical support. Preserve `validation_outcomes_used_for_fitting: false`. |

The cell fields `envelope_basis`, `maximum_qualified_absence_s`, `absence_timebase` and `absence_endpoint` are required by the final loader and **must already be completed prospectively in the rule before validation launches**. The example's nulls are incomplete placeholders, not launch-ready values. Set the basis to `measured_before_this_intervention`; author the supported duration, clock and endpoint before validation, with duration covering the prospective frozen bound and identical clock/endpoint. The assembler preserves every provisional cell field unchanged except appending verified `evidence_refs`; it cannot fill these metadata fields or tune them after validation. Later assembly adds verified evidence/support references and explicit acceptance, not revised cell values. Evidence refs need exact artifact IDs/SHA, prior recorded times and independently verified bytes. Collectively the `supports` tags must include `carry_state`, `absence_survival`, `whole_arm_payload_route`, `settled_placement`, and **later independent** `development_validation`. A construction or compact report alone cannot supply that last tag.

The later final bundle separately needs schema `prior-restart-class-qualification-1`, status `measured_development`, `accepted_at_utc` before release freeze, the complete embedded `class_spec`, empirical-transfer text, these finished cells, and `artifact_files` mapping each artifact ID to a file path/SHA. The protected freeze pins file/canonical bundle/class digests, template mapping, selection rule and absence settings. The existing loader creates role-specific calibration entries with fresh four-source bindings and identical cell evidence refs; do not hand-author a detached “verified” entry.

**B2 remains unsupported.** Selection maps `part:B` to one cell; it does not inspect the “B10” label as an object-ID gate. A B2 payload would therefore select that family cell and face the same actual-state predicates. Check and retain its physical membership/exclusion result; do not enlarge the B10 cell or borrow B2 evidence to make it pass. Unknown support is not automatically the classifier's literal `unknown` result—out-of-envelope state is `fail`, and absent support is `unknown`. If B2 can satisfy the same authored envelope, its unsupported location is not excluded by naming; that requires resolution before claiming the requested scope.
