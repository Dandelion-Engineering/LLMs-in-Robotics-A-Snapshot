# Independent bootstrap evidence assessment

`assess_bootstrap.py` reads retained evidence only. It makes no model, simulator, WSL or network calls. It refuses to read attempt outputs until the supplied shared-queue receipt says `state=succeeded` and `exit_status=0`; `--job-id` additionally binds the expected queue job.

```text
assess_bootstrap.py --evidence <bootstrap-directory> --queue-receipt <terminal-queue.json> --snapshot <immutable-revision/snapshot.json> --job-id <actual-job-id> --output <new-assessment.json>
```

The independent checks cover exact sole bootstrap input; effective ChatGPT/Astra/Max; actual completed turn; native client shutdown exit0; clean outer launcher completion; disabled ambient context; eight startup-file reads evidenced by exact tool output bytes; immutable startup hashes; protected positive controls; all 45 boundary checks repeated by the model and saved exactly; Code Mode API restrictions; fixture observation fields; changed continuity; independently decoded/hashed raw-retention records before and after teardown; observed empty executor/Code Mode namespaces; and absence of actuator submissions through the protected command registry and forwarded broker requests.

Startup evidence accepts either a full command output matching the frozen file hash or exact frozen bytes inside a combined read output that names that path. It never treats model prose or a file-open request alone as a completed read. The initial continuity bytes are obtained from the immutable source ZIP and bound to the runtime input hash; later continuity is an output.

Raw artifact hashes and retained redacted-byte hashes are separate fields. Every retained base64 payload is independently decoded and hashed. Complete before/after snapshot equality establishes persistence across the observed normal shutdown and namespace/broker teardown. It does not establish power-loss/full-host restart recovery or client-failure retention; those require separate evidence. The output names every gate and input hash, preserves failures, and refuses to overwrite an existing assessment.
