The exec object may contain only literal standard command options: cmd, workdir, shell, login, tty, yield_time_ms and max_output_tokens. Reject every other expression, function, assignment, property access, transform, interpolation, spread, computed key, comment, alias, extra statement, duplicate key or command. Do not evaluate JavaScript. Unsupported forms remain unsupported; they may still satisfy an unchanged existing proof.

Inspect the actual prepared output, not a presumed native result. Consume a complete text payload, or a strictly parsed known native result envelope whose sole output payload is consumed in full. Permit only source-bound native status/timing/count wrapper fields outside that payload; do not search for a matching substring, splice text, strip arbitrary prefixes/tails, fill gaps, use hashes in place of bytes or ignore truncation/error markers.
