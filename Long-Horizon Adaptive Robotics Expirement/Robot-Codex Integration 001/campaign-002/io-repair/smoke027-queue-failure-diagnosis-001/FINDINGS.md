The interruption stage failed; resume, both pilots and scored execution were not attempted. This is a bounded infrastructure diagnosis. This rules out the later stdin-close operation as the trigger of this particular observed abort. It does not establish the cause of Smoke026, which lacked this instrumentation, nor prove that thread unload caused the abort. The stage retains injected interruption, old-token denial after retirement, clean owned cleanup and durable retention as true, with no watchdog errors. These narrower observations do not reverse the failed transport verdict.

The pre-exit repair enforced a useful invariant but did not prevent this earlier failure. No V29 resume or unchanged retry is permitted. An earlier, genuinely graceful transport close is a candidate for a separate source review and no-model fixture; it must preserve every byte, all required shutdown RPCs, authentic peer EOF and the original bounds. If no supported route provides those properties, changing the native transport implementation or host is an explicit alternative for director review, not a reason to suppress the error.
