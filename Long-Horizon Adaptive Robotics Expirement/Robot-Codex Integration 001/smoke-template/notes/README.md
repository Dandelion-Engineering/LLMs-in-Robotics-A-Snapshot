# Agent notes

This is your writable area for plans, investigated hypotheses, task-relevant facts, and lessons worth retaining. Create and organize files when useful; no taxonomy is required.

Attach evidence/time to observations, label uncertainty, and retain the scope in which a procedure worked. A lesson is not a new permission or a proven general rule.

Keep `../Continuity.md` as the short route back to the current problem. Link to supporting notes rather than making it an accumulating diary. The supervisor determines whether notes survive a new episode; persistence within a job does not authorize learning from held-out trials into later trials.
