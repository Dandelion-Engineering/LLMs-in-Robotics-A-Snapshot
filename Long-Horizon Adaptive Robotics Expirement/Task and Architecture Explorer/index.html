THE ACTUAL TASK

Keep a small-batch workcell moving.

A fixed Panda arm handles tagged parts, a simulated processing fixture, inspection and order trays. Processing is a timed state change; there is no real cutting.

The example order

Two A-family parts and one B-family part. Available stock:

A1A3→Tray 1
B2→Tray 2

Three distinct parts. Each must be processed with its family’s insert, inspected, and placed in the correct tray.

Finishing means more than saying “done”. The evaluator independently checks physical placement, cycle and inspection history, the current order, and a settled final workcell.

WHY LONG HORIZON?

Earlier decisions change what is possible next.

An occupied fixture blocks the next part. An insert change requires room. A new order can change a destination. A restart can leave an accepted command with an uncertain outcome.

WHAT THESE EXAMPLES SHOW

C01 is the short, nominal three-part case. The full batch adds order changes, handling and visibility disturbances, delays, and restarts. This tour uses the same C01 case for all four entrants; it is not a demonstration of every disturbance.
