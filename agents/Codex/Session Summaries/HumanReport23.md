## What the candidate makes possible

A later agent will face a task the conventional controller cannot already execute. It can inspect structured observations and actual camera pixels, then act through the original lower-level controls. The developer's reachability procedure is isolated from its files and tools. The task says C may recur without telling the agent to program, save coordinates, use a particular file, or adopt a memory strategy.

Each C encounter starts fresh execution namespaces and is prepared to start a fresh conversation. The simulation and persistent filesystem continue across encounters. Ordinary A/B work separates them; future jobs and evaluator truth remain protected. The loader's C replacement occurs only at the explicit job boundary and is separately recorded.

The filesystem now records exact durable mutations rather than inferring changes from snapshots. It retains overwritten and deleted bytes, link/inode changes and operation identities. After an accepted handback, actual conventional resumption and namespace retirement, the framework appends a small terminal receipt without waking the agent. That append preserves the preceding agent-authored bytes. The image sensor delivers real PNG content through the exact app-server dynamic-tool dispatcher; pixel hashes and pinned protocol schemas were checked without running a model.
