# Behavioral evidence tools

Create a derived public corpus from immutable Campaign 002 successes. These tools never invoke historical shell/Python code, the simulator, Robot-Codex, model APIs or a new assessment. [Format](FORMAT.md) and [JSON Schema](schema.json) define the common representation. [Published package](../../Long-Horizon%20Adaptive%20Robotics%20Expirement/Robot-Codex%20Integration%20001/campaign-002/investigation/behavioral-evidence/README.md) is the Session 21 reference.

`inventory.py --output FRESH.json` inventories retained public interfaces and file identities. `build.py --output FRESH_DIRECTORY` authenticates all ten original jobs, dispositions, manifests, admitted evidence and the 974 frozen source bytes. It exports public traces and files and retains explicit unknowns. `recover.py` reads a closed literal syntax subset; it has no execution/evaluation entrypoint. Final files retain their exact original bytes.

`verify.py --output DIRECTORY` independently rereads original evidence without importing the builder or recovery code. It validates all ten source/run bindings, complete public event inventory, every final file, protected Continuity content, independently parsed literal writes, stdout read spans, clock brackets, provenance, diffs, schema and private-channel exclusions. Its dependency-free schema validator evaluates every keyword in this finite schema and rejects unimplemented keywords; the schema is also usable with a standard draft 2020-12 validator. Validation is derived-data QA, not new scoring.

`pack.py --source DIRECTORY --destination FRESH.zip --verification-job ACTUAL_JOB_ID` requires an authenticated successful independent audit, creates a compact public upload, checks every ZIP entry against audited original exported bytes, and rechecks original inputs after compression. Administrative build code/guard inventories and original private traces stay outside that upload. The adjacent manifest binds the ZIP and independent audit.

`publish.py --package PACKAGE_DIRECTORY` authenticates the existing public ZIP and its manifest, writes all 315 entries byte-for-byte into a fresh `corpus/`, and creates lossless ordered parts of larger JSONL traces under `browse/`. It preserves complete records, verifies every unpacked file and concatenated trace, rechecks all original input identities, and checks that Git attributes preserve the evidence bytes. `github-publication.json` records those checks and each part's source offsets/hashes. This adds GitHub access to the already audited export; it does not rebuild or reinterpret the evidence. [GitHub browsing index](../../Long-Horizon%20Adaptive%20Robotics%20Expirement/Robot-Codex%20Integration%20001/campaign-002/investigation/behavioral-evidence/browse/README.md).

Run `test_recover.py` for counterexamples: unknown append before-state, copy/append order, literal Python/newlines, semicolons inside sed replacements, delete-before-append order, path traversal and forbidden executable syntax. These are synthetic parser tests, not model experiments. Sustained inventory/build/audit/compression runs belong in the shared compute queue; record each job ID and require `succeeded` with actual integer exit 0 before using successful outputs. Every failed candidate and job remains preserved. Use a fresh derived directory after corrections.

The source/run adapter is specific to retained Campaign 002 evidence. The normalized contract and finite recovery/verification principles can be reused with a fresh adapter for another authorized evidence source. No prospective recorder change is made here.
