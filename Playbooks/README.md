# Playbooks

Playbooks are on-demand guidance for recurring kinds of work.

A playbook should be read only when its task is relevant. It should explain the purpose, inputs, desired output, useful construction guidance, and important failure modes for that kind of work.

Playbooks do not need to prescribe an agent's internal reasoning. They should state the outcome and the evidence or properties that matter, then trust the agent to choose an effective path.

- [Architecture Map](Architecture%20Map.md) — retrieve and maintain architecture descriptions, revisions, run results and investigation notes.
